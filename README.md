# Flower Letter

A simple couple flower-letter app with a pairing code backend.

## Run locally

```bash
npm install
npm start
```

Then visit:

- http://localhost:3000

## How it works

- Create a 6-digit pairing code
- Share the code with your partner
- When both devices enter the same code, they are paired
- Then choose a flower, write a letter, and preview it

## Notes

This is a lightweight backend for local/demo use. For production, move the in-memory store to a real database such as Supabase or Firebase.
